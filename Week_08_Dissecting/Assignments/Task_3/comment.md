# How the global `AGENTS.md` was created

I asked the coding assistant to create a global `AGENTS.md` in the repository
root. I instructed it to explain the repository structure, summarize the main
week directories, and document general working, validation, and security
guidelines.

The assistant created:

```text
AGENTS.md
```

Because it is in the repository root, the file provides general instructions
for the whole repository. More specific `AGENTS.md` files can be placed in
subdirectories when a particular assignment needs additional guidance.
